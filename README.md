# Simple Interest Calculator

A Bash script that calculates simple interest using the formula:

**Simple Interest = Principal × Rate × Time / 100**

## Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

Enter the principal amount, annual interest rate (percentage), and time in years when prompted.

## Example

For principal 1000, rate 5%, and time 2 years, simple interest is 100.
